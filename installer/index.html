Set up a CheerLights light

Put the CheerLights firmware on an ESP32 board, tell it what is connected, and choose how it gets the color: from the CheerLights app over Bluetooth, or by itself over Wi-Fi. Then it shows the same color as every other CheerLights light.

This page needs to talk to USB devices, which only Chrome and Edge on a computer can do. Open it there to continue.

You need a board with an ESP32, ESP32-S3, C3, C5, C6, or H2 chip, and a USB cable that carries data, not only power. The H2 has no Wi-Fi, so it works over Bluetooth only.

1. Install the firmware

Plug the board into this computer, click Install firmware, and choose its port. The installer picks the right firmware for your board's chip.

This browser cannot install firmware. Use Chrome or Edge on a computer. The installer needs this page to be served over HTTPS.

If the board does not show up in the list, hold its BOOT button while you plug it in. Updating a board you already set up? Leave Erase device unticked, and it keeps its settings and Wi-Fi. When the install finishes, go on to step 2: the board stays dark until it is set up.

2. Connect to the board

The page talks to the board over the same USB cable to set it up. Nothing is sent anywhere else.

3. Tell it what is connected

Or set it up fresh: choose what is connected to it below.

Different LEDs take red, green, and blue in different orders. The page sends two test colors and asks what you see each time.

4. Add its Wi-Fi

Pick the network it should join, or type its name, then add its password. Moving the light between places, such as home and school? Add each network: it keeps up to eight and joins the strongest one in range.

The password goes over the USB cable to the board and stays on it; this page does not keep a copy.
