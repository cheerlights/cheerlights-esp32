Set up a CheerLights light

Put the CheerLights Bluetooth firmware on an ESP32 board and tell it where its LEDs are. Then the CheerLights app for Android sends it the color everyone is sharing.

This page needs to talk to USB devices, which only Chrome and Edge on a computer can do. Open it there to continue.

You need a board with an ESP32, ESP32-S3, C3, C5, C6, or H2 chip, and a USB cable that carries data.

1. Install the firmware

Plug the board into this computer, click Install, and pick its port. The installer picks the right file for your board's chip.

This browser cannot install firmware. Use Chrome or Edge on a computer. The installer needs this page to be served over HTTPS.

If the board does not show up, hold its BOOT button while you plug it in. Updating a board you already set up? Leave Erase device unticked, and it keeps its settings. When the install finishes, go on to step 2: the board stays dark until it is set up.

2. Connect to the board

The page talks to the board over the same USB cable to set it up. Nothing is sent anywhere else.

3. Tell it what is connected

Or set it up fresh: choose what is connected to it below.

Pick your board if it is in the list. Otherwise choose what you wired up and the page will help you find it.

What is connected

Up to 512. A close guess is fine for now.

Which pin are they on?

The page lights each free pin for you, one at a time, in dim white. Say when your LEDs light up.

Which color do they show?

Different LEDs take red, green, and blue in different orders. The page sends one color and asks what you see.

Shape

1 to 255: the brightest the phone can make it. Each LED can draw 60 mA at full white, so keep it low for a long strip on USB power.

A button from a pin to ground that turns the light off and on.

4. Connect from the app

Open the CheerLights app, go to Wearable, tap Find, and choose your board.

To change the setup later, come back to this page and connect again, or forget the settings and start over. This browser keeps a copy of the setup, so if the board is ever erased, this page offers to put it back when you connect.

Firmware and source: cheerlights/cheerlights-esp32-ble. Prefer a terminal? See Set up your board.
